## Terminology

### Cluster
A complete, geographically coherent plan with multiple stops.

### Leg Types
| Type | Purpose |
|------|---------|
| **Fuel** | Food/drink stop (meal or snack) |
| **Spark** | Activity or experience that energizes the night |
| **Browse** | Low-commitment looking/exploring |
| **Lesson** | Learning component (workshop, demo, guided element) |
| **Secret Sauce** | IYKYK hidden gem or surprise element |
| **Detour** | Optional add-on if energy/time permits |

### Reach
Orthogonal high-surprise suggestion — something unexpected but fitting.

### Duration Archetypes
| Archetype | Description |
|-----------|-------------|
| **Micromoment** | Brief, focused experience (under 1 hour) |
| **Evening** | Standard weeknight plan (~3–4 hours) |
| **Afternoon** | Daytime-focused plan |
| **Full Day** | Multi-leg day plan |
| **Serialized** | Multi-part arc across multiple dates |

### Verification Labels
- **Standing** — Permanent fixture
- **Recurring** — Regular programming/events
- **Limited-Run** — Temporary installation or pop-up
- **[UNVERIFIED]** — Not yet confirmed; verify before planning

## Geographic Strategy

**Midpoint Zones** (for meeting after her 5:30 PM departure):
- Midtown West / Hell's Kitchen (near her work)
- Chelsea / Flatiron
- Upper East Side (near you, but requires her travel)

**UES Proximity:** Areas near E 64th or accessible via quick crosstown
**UWS Avoidance:** Do not cluster around W 80s–100s (her neighborhood — keep it special)

**Natural Progression Logic:**
1. Start near her workplace (W 55th) or midpoint
2. Move toward dinner (early-ish)
3. End with low-key Spark or Browse nearby
4. Keep all stops within walkable radius or single short transit hop

## How to Use This Reference

When building a cluster:
1. Pick a geographic anchor (neighborhood or specific venue)
2. Select 2–4 legs using different leg types
3. Ensure pacing respects early hunger and moderate end time
4. Include at least one Secret Sauce or IYKYK element
5. Verify no hard exclusions are violated
6. Add verification labels where applicable

**Example Prompt to LLM:**
> "Hey, I gave my girlfriend these options and she said [X]. Help me build out a few versions of a night that works."

The LLM should use this reference to generate clusters that are:
- Geographically tight
- Paced for early dinner + activity
- Rich in hidden gems and thoughtful details
- Free of banned venues and clichés
