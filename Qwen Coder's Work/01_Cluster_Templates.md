# Sample Clusters (Templates)

*Note: The original repository contained no pre-existing venue data or cluster content to consolidate. This file provides template structures showing how clusters should be formatted when you ask an LLM to build plans.*

---

## Cluster Template Structure

```
### [Cluster Name]
**Neighborhood:** [Area]
**Duration:** [Evening / Afternoon / Micromoment / Full Day / Serialized]
**Vibe:** [2–3 descriptors]

**Leg 1 — [Type]:** [Venue/Activity]
- Details, timing, why it fits
- [Verification Label if applicable]

**Leg 2 — [Type]:** [Venue/Activity]
- Details, timing, why it fits
- [Verification Label if applicable]

**Leg 3 — [Type]:** [Venue/Activity]
- Details, timing, why it fits
- [Verification Label if applicable]

**Secret Sauce:** [Hidden IYKYK element]
**Detour (optional):** [Add-on if energy permits]
```

---

## Leg Type Quick Reference

| Code | Type | Best For |
|------|------|----------|
| F | Fuel | Early dinner, snack, drink |
| S | Spark | Energizing activity or experience |
| B | Browse | Low-commitment exploration |
| L | Lesson | Workshop, demo, guided learning |
| SS | Secret Sauce | Hidden gem, surprise reveal |
| D | Detour | Optional extension |
