## Structure for IYKYK Lists

Each list should be:
- **Tight:** 3–7 items max
- **Specific:** Include cross-streets or exact locations
- **Labeled:** Add verification status where known
- **Categorized:** Group by vibe, neighborhood, or experience type

## How to Use

When an LLM generates clusters, it can pull from these micro-lists to add Secret Sauce legs or Detours. Each entry should include:
1. Name and location
2. What makes it IYKYK
3. Best time to visit
4. Verification label if applicable

*Example:*

> Tiny sound installation in a lobby nobody notices. Standing. Best visited weekday evenings when quiet.
