# README — Date Night Planning System

## What This Is

A consolidated, minimal reference system for building thoughtful, geographically coherent date night plans ("clusters") for a couple in NYC with specific tastes and constraints.

## Files Included

| File | Purpose |
|------|---------|
| `00_Date_Night_Reference.md` | Core context: locations, constraints, tastes, terminology, geographic strategy |
| `01_Cluster_Templates.md` | Template structures for building evening clusters |
| `02_IYKYK_Micro_Lists.md` | Placeholder for curated hidden-gem lists by category |
| `03_Serialized_Arcs.md` | Placeholder for multi-date narrative arcs |
| `04_Weekend_Deep_Dives.md` | Placeholder for longer day-long explorations |

## How to Use

1. **Start here:** Read `00_Date_Night_Reference.md` to understand the core context, constraints, and terminology.

2. **Build a cluster:** Use the templates in `01_Cluster_Templates.md` to structure an evening plan.

3. **Add hidden gems:** When you have venue research data, populate `02_IYKYK_Micro_Lists.md` with specific spots.

4. **Plan arcs:** Use `03_Serialized_Arcs.md` for multi-date storylines.

5. **Weekend planning:** Use `04_Weekend_Deep_Dives.md` for fuller day experiences.

## Prompting an LLM

Once you've given your girlfriend options from this system and she responds, prompt an LLM like this:

> "Hey, I gave my girlfriend these options and she said [X]. Help me build out a few versions of a night that works."

The LLM should use the reference framework to generate clusters that are:
- Geographically tight (all stops walkable or one short transit hop)
- Paced for early dinner + activity (she gets hungry early, doesn't stay out late)
- Rich in hidden gems and thoughtful details
- Free of banned venues (no theater, no loud music, no basic strolls, no meal-only plans)
- Aligned with tastes (oddities, IYKYK, avant-garde, obscure history, niche culinary, whimsy ↔ serious)

## Important Notes

**The original repository contained no pre-existing venue data.** These files provide the *structure* and *framework* for planning, but actual venue names and details need to be added through future research prompts or manual curation.

**Verification labels matter:** When adding venues, mark them as:
- **Standing** — Permanent fixture
- **Recurring** — Regular programming/events
- **Limited-Run** — Temporary installation or pop-up
- **[UNVERIFIED]** — Not yet confirmed; verify before planning

## Hard Exclusions (Do Not Violate)

- ❌ Traditional theatrical productions
- ❌ Loud music venues
- ❌ Basic park/waterfront strolls (unless elevated)
- ❌ Meal-only plans (must include activity)
- ❌ International Center of Photography as anchor
- ❌ La Noxe as anchor
- ❌ UWS 80s–100s clusters
- ❌ Shukette + High Line + Chelsea galleries combo
- ❌ Brooklyn Museum as anchor
- ❌ Coney Island / boardwalk clusters
